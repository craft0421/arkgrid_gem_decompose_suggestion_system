아크 그리드 젬 분해 도우미

젬 탭이 가득 찼을 때, 앞으로 젬을 더 깎아도 쓰일 가능성이 낮은 젬부터 분해 후보로 보여 줍니다. 계산은 이 브라우저 안에서만 합니다.

계산 가정과 사용 방법눌러서 접기·펴기

계산 가정

  • 아크 그리드 프리셋은 1개만 고려합니다. 다른 프리셋에서만 쓰는 젬은 잠금으로 표시하면 판정에서 빠집니다.
  • 앞으로 깎을 젬은 기본값으로 영웅 젬(가공 9회, 다른 항목 보기 2회)입니다. 희귀·고급으로 바꿀 수 있습니다.
  • 새 젬은 질서·혼돈 반반, 타입은 같은 확률로 나오고, 가공은 젬 가치의 기대값이 가장 높아지게 진행한다고 봅니다. 골드 비용은 따지지 않습니다.
  • 전투력 계수는 딜러 기준입니다. 서포터는 계수 측정이 끝나면 열립니다.

사용 방법

  1. 코어 설정에서 장착한 코어 6개를 고릅니다.
  2. 보유 젬의 게임 화면에서 젬 읽기로 젬 탭을 읽고 확인으로 반영합니다. 새로 깎은 젬은 보유 젬 목록을 펼쳐 젬 추가로 넣고, 다른 프리셋에서 쓰는 젬은 잠금을 겁니다.
  3. 계산을 눌러야 분석합니다. 사용 확률이 낮은 젬부터 보여 줍니다. 젬 하나를 고치고 다시 계산하면 바뀐 부분만 따로 표시됩니다.

1. 코어 설정

무기 코어 계산용 캐릭터 값

혼돈 별 코어가 '무기'일 때만 필요합니다. 캐릭터 불러오기로 채우거나 직접 넣으세요.

캐릭터 이름을 넣으면 아래 다섯 값을 공식 API(전투정보실)에서 채웁니다. 장비가 바뀌었다면 다시 불러오세요.

2. 보유 젬

게임 화면에서 젬 읽기

화면은 이 브라우저 안에서만 처리하고 어디에도 보내지 않습니다

사용 방법
  1. 게임 해상도는 1920×1080 이상을 권장합니다. 아크 그리드 → 젬 탭을 엽니다.
  2. 쓰지 않는 아크 그리드 프리셋으로 바꿔 모든 젬을 장착 해제합니다. 젬 목록에는 다른 코어에 장착된 젬이 나오지 않기 때문입니다. 해제가 어렵다면 코어를 하나씩 선택해 목록 맨 위(장착 젬)를 보여 주세요. 그 장착 젬도 더해집니다.
  3. 화면 공유 시작을 누르고 게임 창(또는 화면)을 고릅니다.
  4. 질서 코어를 선택한 채 목록을 맨 위부터 끝까지 스크롤하고, 혼돈 코어로 바꿔 한 번 더 스크롤합니다. 휠을 한 칸씩 굴리고 화면이 멈춘 순간을 읽으므로, 오른쪽 읽은 위치 막대가 채워지는지 보며 내리세요. 위아래로 여러 번 오가도 중복되지 않습니다.
  5. 개수가 게임의 젬 보유 수량(질서·혼돈)과 맞으면 공유 끝내기 → 노란 줄을 중심으로 틀린 값을 표에서 고치고 → 확인을 누릅니다.
잘 안 될 때
화면 공유가 안 됩니다
PC의 크롬이나 엣지에서 열어 주세요. 휴대폰이나 일부 브라우저는 화면 공유를 지원하지 않습니다. 스크린샷을 찍어 캡처 파일 넣기로 넣어도 됩니다.
젬이 인식되지 않습니다
공유 화면 보기로 파란 상자(기준 위치)와 초록 상자(읽은 줄)가 젬 목록에 맞는지 보세요. 어긋나면 해상도를 1920×1080, 화면을 창 모드로 바꾸고 21:9 강제 설정을 끄세요.
노란 줄(확인 필요)이 많습니다
해상도가 낮으면 글자가 작아 자주 생깁니다. 1920×1080 이상을 권장합니다. 표시가 너무 많거나 적으면 허용 오차를 조절하세요. 값은 표에서 바로 고칠 수 있습니다.
개수가 모자랍니다
스크롤을 한 번에 많이 내리면 줄을 놓칩니다. 오른쪽 읽은 위치 막대의 빈 곳(몇 번째 줄인지 표시)으로 다시 스크롤해 보여 주면 채워집니다.
게임 창을 보는 동안 멈추나요?
이 페이지가 가려져 있어도 계속 캡처합니다.

인식한 젬

아직 인식한 젬이 없습니다. 화면 공유를 시작하거나 캡처 파일을 넣으세요.
